# SheAlert 🚨

### Women Safety Web Application

SheAlert is a full-stack women safety web application developed to provide quick emergency support and enhance personal security through smart digital solutions. The application focuses on real-time assistance, emergency communication, and safety-focused features for users during critical situations.

---

## ✨ Features

* 🚨 SOS emergency alert system with live location sharing
* 🎙️ Voice recording for emergency evidence collection
* 🛡️ Threat Analyzer to identify potentially unsafe situations
* 📍 Safe Path Assistant for safer route suggestions
* 👥 Emergency contact management
* 🔐 Secure user authentication and login system
* 📱 Responsive and user-friendly interface
